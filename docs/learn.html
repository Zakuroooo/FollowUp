FollowUp

Field guide — the whole app in 10 minutes

What we built for Denise, how it works, and the questions Gushwork will ask you. Read it twice, then explain it out loud without looking.

Live: followup-indol-seven.vercel.app · Code: ~/Desktop/followup

01The problem, in one line

Denise runs a refrigeration repair shop. Requests come from 5 places (calls, texts, web form, referrals, a notebook). She forgot one follow-up and lost a $2,000 job.

Her exact ask: “wake up and know who I need to call today.” So the main screen is the Call list, not a dashboard.

Simple words: problem “data store karna” nahi hai — problem “yaad dilana” hai. App ka kaam hai roz subah batana: kisko call karna hai, aur kyun.

02What the app does (Version 1)

Next.js renders pages on the server. Server Actions handle form submits (no separate API needed). Supabase gives Postgres + login. RLS (Row-Level Security) means the database itself only returns your rows — owner_id = auth.uid().

RLS kyun? Agar code mein bug ho aur filter bhool jao, tab bhi database doosre user ka data nahi dega. Security code pe nahi, database pe tiki hai.

04The brain — lib/rules.ts

One pure function, classify(job, now, today), decides if a job goes on the call list and why. No database, no clock inside — time is passed in, so it’s easy to test (18 tests).

RuleGoes on the list when…
ReminderShe set a follow-up date and it’s today or past (beats every other rule)
EmergencyStage is New and marked urgent → always on top
New requestNobody has called back yet (overdue after 24 h)
Quote to sendCustomer is waiting on our price (overdue after 24 h)
Follow-upQuote sent, no contact for 2+ days
ScheduleThey said yes but no visit date
Finished?Visit date has passed — mark it done
Urgency, the safe direction: rules flag “freezer down / not holding temp / food at risk”. In V2, AI may only raise urgency, never lower it. A missed emergency costs more than a false alarm.

06Questions to practise out loud

  1. Why a call list and not a Kanban board?Denise asked “who do I call today”. A board shows where jobs are; it doesn’t tell her what to do. Board = All jobs page, secondary.
  2. Why rules, not AI, for the call list?Rules are predictable, free, testable, and explainable to a non-technical owner. AI is for messy input (V2: paste a text → job).
  3. What is RLS, and what happens without it?Database-level filter per user. Without it, one missing where leaks every customer’s data.
  4. How does the guest demo stay private?Supabase anonymous sign-in → a real user id → seed function inserts jobs owned by that id → RLS.
  5. What would you build next?Public request form so web leads land automatically, a 7 AM email digest, and an emergency alert. Tech scheduling after that — she said it’s “nice later”.
  6. What did you skip on purpose?Invoicing, tech dispatch, SMS sending, multi-user teams. She said “nothing fancy” — scope was her words.
